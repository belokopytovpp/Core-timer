# История версий

Снимки состояния до перехода на git. Начиная с v4 историю ведёт сам git —
вручную копии больше не делаются, каждый коммит и есть версия.

Файлы заморожены: не править. Нужна правка — она идёт в `index.html`.

Различия сверены с содержимым файлов, а не взяты со слов.

| Версия | Интервалы | Речь | Иконка | Метки предпросмотра |
|---|---|---|---|---|
| v1 | 80 / 100 | есть | нет | нет |
| v2 | 80 / 100 | убрана | нарисована в коде | нет |
| v3 | 60 / 80 | убрана | нарисована в коде | нет |
| v4 | 60 / 80 | убрана | файлы PNG | есть |

**v1** — первая утверждённая по дизайну. Ещё с голосовым проговариванием
упражнений, интервалы 80 и 100 секунд.

**v2** — речь заменена звуковыми сигналами: она вызывала рывки анимации кольца,
лечения не нашлось. Оптимизирована отрисовка.

**v3** — интервалы сокращены до 60 и 80: прежние давали слишком долгий отдых.
Добавлено нажатие на отрезки, экран зафиксирован от прокрутки.

**v4** — то, что лежит на сайте. Добавлены метки предпросмотра ссылки,
иконка переведена с рисунка в коде на файлы PNG, исправлена полоса от старой
кнопки между «Сбросом» и «Паузой».

Про иконку подробнее: в v2 и v3 она была объявлена как картинка, нарисованная
прямо в адресе ссылки (SVG внутри `data:`). iOS такие не принимает — на экране
«Домой» выходил серый квадрат с буквой «К». В v4 это заменено на обычные файлы
`apple-touch-icon.png` и `icon-512.png` плюс манифест.

`core-timer-v4.html` побайтово совпадает с `index.html` на момент добавления
в репозиторий. Дальше `index.html` будет меняться, а v4 останется снимком.
