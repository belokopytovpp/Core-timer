# Инструменты

Вспомогательные страницы. К сайту отношения не имеют, на работу таймера не
влияют, но Netlify публикует их вместе с ним — открываются с телефона по
адресам `core-timer-petr.netlify.app/tools/sound-lab.html` и
`.../tools/volume-check.html`.

## sound-lab.html

Звуковая лаборатория: все тембры, которые перебирались при выборе сигналов, с
кнопками для прослушивания и ползунком громкости. В итоге выбрана калимба;
маримба, колокольчик, дерево, щипок, барабан, стекло, блип и поющая чаша
остались здесь.

Смысл файла: если понадобится поменять сигналы, не нужно перебирать вслепую —
открыть, послушать, назвать вариант. В `index.html` лежит только победивший
тембр, альтернативы существуют лишь тут.

## volume-check.html

Проверка пяти боевых сигналов на той же громкости, что в приложении: старт,
велосипед, супермен, предупреждение, финиш. Лаборатория его частично
перекрывает, но для проверки «не режет ли ухо на максимуме» удобнее.
